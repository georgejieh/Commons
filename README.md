# Commons

A single-player roguelike deckbuilder built on the card game Fight the Landlord (斗地主).

## Building from source

You need [Godot 4.7.2](https://github.com/godotengine/godot/releases/tag/4.7.2-stable) and [Git LFS](https://git-lfs.com/).

```bash
git lfs install
git clone https://github.com/georgejieh/Commons.git
```

Open the folder in Godot.
