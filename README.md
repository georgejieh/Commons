# Commons

A single-player roguelike deckbuilder built on the card game Fight the Landlord (斗地主).

## Download and play

1. Open the [latest release](https://github.com/georgejieh/Commons/releases/latest).
2. Download the file for your system: the Windows setup, the macOS `.dmg`, or the Linux AppImage.
3. Open it and play. The release page explains the warning unsigned builds show on first launch, and the extra step Linux needs.

Saves live in your user data folder, so installing a new version never touches them.

## Building from source

You need [Godot 4.7.2](https://github.com/godotengine/godot/releases/tag/4.7.2-stable) and [Git LFS](https://git-lfs.com/).

```bash
git lfs install
git clone https://github.com/georgejieh/Commons.git
```

Open the folder in Godot.
