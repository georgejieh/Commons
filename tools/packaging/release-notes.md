## Download and play

- **Windows:** download the setup file and run it, or use the zip. If SmartScreen appears, choose More info, then Run anyway.
- **macOS:** open the `.dmg` and drag Commons to Applications. The first time you open it, macOS will block it. Go to System Settings, then Privacy & Security, and choose Open Anyway.
- **Linux:** download the AppImage, run `chmod +x` on it, then open it. A tarball is also included.

Builds are unsigned for now, which is why Windows and macOS show those warnings. Check a download against `SHA256SUMS.txt` if you want to confirm it's intact.
